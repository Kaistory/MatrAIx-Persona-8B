# web-sidecar_vita-drive

Local Web sidecar for the **VoiceLab / Vita Drive Assistant Lab** stack (Frontend, Backend API, Python Agent).

## Port Mapping ra URL máy tính (Host machine)
- `8888:8888` -> Web Frontend: `http://localhost:8888`
- `3001:3001` -> Backend API: `http://localhost:3001`
- `8787:8787` -> Agent Server: `http://localhost:8787`
