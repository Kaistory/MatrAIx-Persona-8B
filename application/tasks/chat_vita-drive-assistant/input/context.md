# Bối cảnh Hệ thống Trợ lý Lái xe Vita (Vita Drive Assistant)

Vita là trợ lý giọng nói & tương tác thông minh trên khoang lái ô tô (In-Cabin Assistant), hỗ trợ điều khiển phương tiện (điều hòa, cửa sổ, gạt mưa, đèn), dẫn đường, giải trí và đảm bảo an toàn vận hành trong các trạng thái lái xe khác nhau.
