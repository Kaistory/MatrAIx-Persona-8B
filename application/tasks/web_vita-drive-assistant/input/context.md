# Bối cảnh bài toán

Bạn đang trải nghiệm bảng điều khiển xe thông minh **Vita Drive Assistant Lab** trên nền web tại:
http://172.17.0.1:5173/
*(Lưu ý: Nếu gặp màn hình yêu cầu đăng nhập, nhập mật khẩu là `dev` rồi bấm nút "Đăng nhập" để vào buồng lái).*

## Tính năng và tương tác trên Dashboard xe:
- **Vehicle Stage & Controls**: Khu vực hiển thị mô hình xe 3D và các nút điều khiển nhanh xe (đèn, cửa kính, khóa cửa, trạng thái xe).
- **Climate Control Bar**: Thanh điều khiển điều hòa nhiệt độ, tốc độ gió, sưởi/làm mát ghế.
- **Navigation & Now Playing**: Khung bản đồ dẫn đường và trình phát nhạc đa phương tiện.
- **Chat / Voice Assistant**: Khung tương tác hội thoại với trợ lý giọng nói thông minh Vita.

Hãy đóng vai Persona của bạn, khám phá giao diện dashboard xe, thử nghiệm các tính năng điều khiển và trợ lý, sau đó đưa ra đánh giá về mức độ tiện dụng, thẩm mỹ và trải nghiệm tổng thể.
