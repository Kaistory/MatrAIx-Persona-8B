# Bối cảnh Tác nhân Xe Thông Minh Vita Agent (Autonomous In-Cabin Agent)

Vita Agent là hệ thống tác nhân đa tầng (LangGraph Agent Runtime) vận hành trên xe thông minh, có khả năng phân tích ý định, điều hướng an toàn (Policy Gate), gọi công cụ điều khiển phần cứng xe (Vehicle Tool Execution) và phản hồi tương tác bằng tiếng Việt tự nhiên.
